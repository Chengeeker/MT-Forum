# MT论坛

Flutter Material 3 Android 客户端，包名 `bbs.binmt.cc`。

首页、板块/导读、帖子阅读、历史记录、原生登录和个性化使用 Flutter Material 3。图片支持共享元素打开动画、多图缩放画廊；帖子内 HTTPS 视频直链使用原生播放器。页面顶栏、设置控件、字体偏好和悬浮底栏复用 Review 组件，液态玻璃可应用于悬浮底栏。登录请求由隐藏的同源 WebView 提交到论坛以共享官网会话；回复、引用回复、发帖及其他同源表单由原生 M3 控件填写，写请求不会自动回退网页或重试。

开发进度、错误复盘、功能边界和验收说明见 [开发文档](docs/DEVELOPMENT.md)。完整本地副本：`D:\App\开发文档\MT论坛.md`。

消息是底栏常驻页面，游客先看到登录提示；登录完成后直接显示消息，取消登录仍停留在消息页。发帖/回复和自己的账号内容等入口在游客状态打开原生登录页，取消保留当前页面。

搜索等待期间只显示加载状态，结果复用原生帖子列表，展示官网返回的作者、头像、摘要及统计，沿官网下一页分页。首页最新帖子从最新发表导读继续加载，按需构建可见帖子、合并去重；加载失败保留已有内容并提供重试。

消息/提醒、资料、收藏、排行榜、签到、搜索结果及注册的同源入口统一进入原生内容页。正文由 Flutter 渲染，表单使用 M3 输入/选择/按钮；唯一可见 WebView 入口为明确标注的 QQ 官方授权。网站复杂插件、附件上传和脚本专有验证仍需分别适配，不以通用表单渲染代表全站功能验收。入口清单见 [原生适配审计](docs/NATIVE_UI_AUDIT.md)。

我的页面顶部显示当前账号头像、昵称和 UID，点击进入原生资料与账号管理页；退出登录统一保留在该管理页，加载失败也可退出。退出会清理本机论坛会话并使旧账号页面失效。板块页展示图标、统计和简介，置顶帖单独分组；板块、首页最新、收藏及浏览历史共用帖子卡片，显示可读取的头像、作者/UID、身份标签和正文摘要。置顶使用紧凑红色标签，收藏在管理模式中选择并确认删除。“我的”不重复提供底栏的首页跳转。帖子内底部展开快捷回复工具栏，支持草稿收起恢复、引用和 BBCode；默认头像使用论坛原图。首页排行榜使用带排名序号的紧凑列表。签到采用专用状态与统计布局；消息页使用 M3 一级/二级顶栏分类，子分类随官网当前页面读取，磨砂分界固定在最后一行之下；空状态、资料字段和标准数据表格使用原生布局。引用回复将引用预览与输入区分开，支持移除引用，提交失败保留输入。

已按官网登录页核对用户名＋密码、Email＋密码和 QQ 授权入口。前两种使用原生表单；QQ 进入专用 M3 外壳中的官方授权界面。协议与验证码边界见 [登录协议核对](docs/LOGIN_PROTOCOL.md)。

静态分析：`D:\flutter_sdk\bin\cache\dart-sdk\bin\dart.exe analyze --format=machine lib test`。

发布及回归：`pwsh -File tool/build_release.ps1 -RunChecks`。执行实际登录 JS 资产检查，并从临时 ASCII 源码目录执行论坛/Widget/明暗预览检查后，使用 Gradle 离线构建仅含 ARM64 的 release，并使用本机指定 BKS 对应的签名；签名配置和密钥不提交。省略 `-RunChecks` 可只构建，详见开发文档。

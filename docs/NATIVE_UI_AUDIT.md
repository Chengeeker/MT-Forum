# 原生入口审计（2026-10-26）

本次用户要求：回复不再跳官网编辑器，排查所有同类入口。此前只有登录门槛原生化，登录后多数功能仍由网页承接；这是上一轮遗漏。

| 首页/板块发帖 | 官网 post 页面 | 同一原生编辑器，保留官网帖子分类和表单字段 |

| 签到 | 通用 HTML 混排、CSS 数字与空白 | 专用 M3 状态/统计/规则/排行布局，用户点击后请求当次同源 JD_sign，结果重读核对 |

| 错误页“打开官网”、帖子“官网页面” | 网页后备入口 | 已移除，保留重试/复制链接等原生操作 |

## 1.5.0 消息顶栏分栏

- 一级导航为消息、我的帖子、坛友互动、系统提醒、应用提醒；二级项不硬编码，逐页读取官网 `.tb`，限制在同源的当前消息/提醒分类下。
- 嵌入式消息页移除正文内重复的分类栏和官网侧栏导航；像发送消息、筛选设置这类页面操作仍保留在原生内容区。
- `ReviewFrostedAppBar` 的底边随最末一行分栏移动；当前响应没有子分类时仅显示一级分栏。滚动正文的顶部留白与可见分栏行数同步。
- 测试覆盖官网“我的帖子”六个子分类、操作按钮保留、分类切换与一行/两行顶栏分界。其他分类子项继续依当前官网响应展示，不预设未核对的内容。

## 防回归边界

- `openForumWeb` 名称为兼容旧调用点暂留，但只分派原生页面；没有通用 `openWeb` 函数。
- 生产源码仅有一个可见 `ForumWebPage` 构造调用，位于 QQ 授权入口且显式 `qqLogin: true`。隐藏 BrowserReader 仍用于官网访问验证与登录传输。
- 不执行原网页脚本、内联事件或编辑器 iframe。动态原生表单使用当前 HTML 的隐藏参数、已选项和按钮；站外 action、非 GET/POST 方法以及站外重定向在请求边界拒绝。
- 服务端 Set-Cookie 写回 Android CookieManager，下一跳重新读取共享会话。302/303 等转换为 GET，不重发原 POST；失败不自动重发，编辑内容保留。无法确认发帖成功时明确提示先刷新核实。
- 原生编辑器是文字/BBCode 表单；附件上传、插件脚本专有交互、短信发送及复杂风控验证码未完成适配。不会用可见网页兜底，但也不把入口原生化当作这些功能已经完成。
- 已识别的删除/退出链接及删除类提交使用原生确认；账号安全、未知插件动作仍需单独审核，不通过去除页面事件就宣称所有操作与网站等价。
- 本轮只读查看官网回复/消息/签到结构，没有实际发布帖子、回复、私信或执行签到。自动化使用合成 token 与内容，不保存真实账号表单或私信内容。

## 原生排版复盘（1.3.4）
- “Flutter 渲染 HTML”与“页面已完成原生排版”不是同一验收项。签到已用独立语义模型；消息导航/空状态、资料字段、标准数据表格和表单使用对应 M3 控件。
- 表格只在表头、行列结构一致且不含表单控件时转换；不规则表格保留内容，不能因转换而静默丢掉合并单元格、操作或选择框。普通正文链接保留，网站装饰导航不再伪装为正文。
- 实测只读官网签到和消息空页，测试覆盖合成签到/引用等状态；未提交真实私信、回复或签到。真实非空私信、复杂插件页面仍需逐项设备验收，不能用通用适配器宣称所有界面均已完成视觉验收。
## 1.4.0 快捷回复与收藏/历史复盘
- 我的“论坛首页”重复入口已删除；只有底栏负责回首页。资料/退出仍集中在账号页。
- 收藏列表不再走通用表单渲染，按收藏行解析帖子/板块，默认浏览卡片，管理时展开复选框与确认删除，保留原动态表单和分页/分类。
- 帖子详情头像与默认头像、板块紧凑红色置顶、首页最新/收藏/历史摘要共用组件；快捷回复在帖子底部展开，保留引用/草稿/发送校验。
- 本地图片上传仍未实现，快捷栏“网络图片”只插入 HTTPS 图片地址；摘要只 HTTP 读取，失败不占隐藏浏览器或强制网页后备。

- 1.4.1：底栏移除按压时重复的水波纹、玻璃发光与形变，保留选中胶囊移动及原有触感；标准底栏保留焦点提示。

- 1.4.2：消息与首页/发现同属底栏页面，顶栏通知切换至同一标签，消息分类原位切换；访客显示登录提示，切换账号使旧页面和请求失效。

- 1.5.1：消息一级栏使用可横向滚动的自然宽度，字体放大时同步增加分栏高度，避免五等分导致文字被裁切。官网未返回二级项时只显示一级栏；用户截图中二级项缺失的原因尚未通过真实登录页面确认。

- 1.5.2：通知“查看”中的帖子跳转支持 `ptid` 及仅含 `pid` 的同源 findpost 地址；未知入口如果返回帖子主题与正文，转入原生帖子页并复用已取得的内容。回复和收藏使用已解析的真实帖子编号，无法确定编号时不发送无效请求。合成数据已覆盖，真实账号通知链接和回复楼层定位仍待验证。

## 1.0.0+21 搜索与首页分页
- 搜索取令牌期间不再暴露首页 DOM；返回搜索结果后原位呈现共用原生帖子列表，并解析作者/头像、摘要、统计与官方分页。搜索失败只展示错误及重试，不返回原始首页布局。
- 首页最新与导读分页连接，惰性渲染、去重和失败重试；首页边缘拉伸关闭。专项模拟数据检查通过，真实网络搜索和设备闪烁尚未验收。

## 1.0.0+23 排行榜
- 总览和用户/帖子/版块排行统一使用专用原生列表：名次、单次标题、作者头像/昵称和实际统计。总览不再被当作消息列表，详细榜单不再被当作网页表格。
- 分类与榜单放入磨砂顶栏、时间范围采用原生选择项；更多与筛选原位切换。使用官网四类公开响应及窄屏双倍字号检查，真实设备观感尚未验收。

## 1.0.0+24 首页最新帖子批量加载
- 首页与发现页“最新发表”统一为官方导读分页数据和相同的 `ThreadTile` 渲染。首页不再先露出首页的少量预览再替换列表，也不再在每个帖子滚入视口时额外请求整篇帖子来补摘要。
- 首次展示约 20 条；若官方一页不足 20 条且仍有下一页，会先补齐到该批次再展示。滚动接近末尾（剩余不足 600dp）时才取下一批。保留懒构建、分页去重、失败重试，以及刷新时旧列表继续可见。
- 列表响应未提供摘要/角色/点赞时就不额外逐帖抓取，因此缺少这些字段时不展示；避免恢复导致首页卡顿的逐条请求。
